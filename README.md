# international_trade_legal_document_automation Flow

This project defines a declarative CrewAI Flow in `src/international_trade_legal_document_automation/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/international_trade_legal_document_automation/flow.yaml` to change the flow. Add reusable crews under `src/international_trade_legal_document_automation/crews/`, custom Python tools under `src/international_trade_legal_document_automation/tools/`, and shared knowledge files under `src/international_trade_legal_document_automation/knowledge/`.
